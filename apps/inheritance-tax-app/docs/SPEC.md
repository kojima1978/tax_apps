# 相続税シミュレーター 仕様書

## 1. 概要

相続財産額に応じた相続税額をシミュレーションする業務用Webアプリケーション。税理士法人の担当者が顧客への説明・提案に使用することを想定。全UIは日本語。

### 対象ユーザー

- 税理士法人の担当者（PC利用が主、タブレットでの顧客説明も想定）

### 動作環境

- モダンブラウザ（Chrome, Edge, Firefox, Safari）
- Docker コンテナ上で動作（ポート: 3004, basePath: `/inheritance-tax-app`）。Express 5 のサーバーが画面を配信し（dev は Vite をミドルウェアとして組み込む）、外部アプリ向けの相続税計算 API（`POST /api/calculate`、README 参照）も受け持つ。画面の計算はブラウザ内で完結し、API は呼ばない

### 2.6 分割シミュレーションページ（`/split`）

各相続人の取得額を自由に設定し、取得額を一定額ずつ変動させた場合の税額変化を一覧テーブルで確認する。

#### 入力

| 項目 | 型 | 単位 | バリデーション |
|------|-----|------|-------------|
| 相続人の構成 | HeirComposition | - | 配偶者または順位いずれか必須 |
| 遺産総額 | number | 万円 | > 0 必須 |
| 各相続人の取得額 | HeirAcquisition[] | 万円 | 合計 = 遺産総額 必須 |
| 各相続人の増減額/行 | number | 万円 | 自動調整対象は設定不要 |
| 自動調整対象 | radio | - | 1人選択必須 |
| 行数（基準から上下） | number | - | 1〜20（デフォルト 5） |

#### 取得額入力の補助機能

- **「法定相続分で入力」ボタン**: 遺産総額 × 法定相続分割合を各相続人の取得額に自動セット

#### シミュレーション生成ロジック

1. 各相続人の基準取得額と増減額/行を元に、基準から上下 N 行のシナリオを生成
2. 自動調整対象の相続人は、他の増減分を吸収して取得額合計 = 遺産総額を維持
3. 誰かの取得額がマイナスになる行は自動除外
4. 法定相続分による分割行を別途計算し、比較用に常時表示

#### 計算仕様

- **相続税の総額は法定相続分ベースで算出**（取得額の配分に関わらず固定）
- 取得額の配分に応じて按分税額を計算
- 2割加算（第3順位）・配偶者控除を適用
- 各相続人の最終税額 = 按分税額 + 2割加算 − 配偶者控除

#### 出力

- サマリーカード4枚: 遺産総額 / 基礎控除額 / 課税遺産総額 / 相続税の総額
- 凡例: 基準行（緑）/ 法定相続分行（青）の色分け説明
- 結果テーブル:
  - 列構成: # / 取得額（相続人別）/ 税額（相続人別）/ 税額合計 / 基準との差 / 法定との差
  - 法定行（青系ハイライト）: テーブル最上部に固定表示
  - 基準行（緑系ハイライト）: 入力した取得額に対応する行
  - 差額表示: 赤 = 増税、緑 = 節税、灰 = ±0

### 2.7 賃貸不動産シミュレーションページ（`/real-estate`）

現金の一部を賃貸不動産へ組み替えた場合に、評価額の圧縮で相続税がどれだけ変わるかを比較する。

#### 入力

| 項目 | 型 | 単位 | バリデーション |
|------|-----|------|-------------|
| 相続人の構成 | HeirComposition | - | 配偶者または順位いずれか必須 |
| 遺産総額 | number | 万円 | > 0 必須 |
| 配偶者取得割合 | SpouseAcquisitionMode | - | 3モード選択 |
| 投下資金 | number | 万円 | > 0 かつ遺産総額以下 |
| 圧縮率 | number | % | 0〜100（デフォルト 40） |
| 借地権割合 | number | % | 0〜100（デフォルト 60） |
| 借家権割合 | number | % | 0〜100（デフォルト 30） |

#### 計算（`utils/realEstateCalculator.ts`）

1. 評価額（自用地・自用家屋相当）= floor(投下資金 × (1 − 圧縮率))
2. 賃貸後の評価額 = floor(上記 × (1 − 借地権割合 × 借家権割合))
3. 不動産購入後の遺産額 = (遺産総額 − 投下資金) + 賃貸後の評価額
4. 現状と購入後それぞれで相続税を計算し、節税額と納税後の手取りの差を出す

#### 出力

- 税額サマリー（現状 → 不動産購入後）
- 不動産評価額の計算過程
- 現状と投資後の比較表
- 注意事項（印刷時は1行にまとめる）

### 2.8 税務タイムラインページ（`/timeline`）

二次相続が何年後に起きるかで、一次相続の配偶者取得割合の最適解がどう変わるかを比較する。

#### 入力

| 項目 | 型 | 単位 | バリデーション |
|------|-----|------|-------------|
| 相続人の構成 | HeirComposition | - | 配偶者あり必須 |
| 対象者の相続財産額 | number | 万円 | > 0 必須 |
| 配偶者の固有財産額 | number | 万円 | 任意（デフォルト 0） |
| 年間収支（配偶者の資産増減） | number | 万円/年 | マイナス可 |
| シミュレーション年数 | number[] | 年 | 5 / 10 / 15 / 20 / 25 / 30 から複数選択（デフォルト 5・10・15） |

#### 計算（`utils/timelineCalculator.ts`）

- 配偶者取得割合 100%〜0%（5%刻み）× 選んだ年数の組み合わせで、1次相続税 + 2次相続税の合計を出す

#### 出力

- 年数ごとの最適割合のサマリー
- タイムライン比較表（年数ごとに 2次遺産額 / 2次税額 / 合計税額）
- 前提条件は「計算する」を押した時点の入力値から組み立てる（再計算せずに印刷しても表と食い違わない）

## 3. 計算仕様

### 3.1 基礎控除

```
基礎控除額 = 3,000万円 + 600万円 × 法定相続人数
```

### 3.2 相続税率テーブル（超過累進税率）

| 法定相続分に応じた取得金額 | 税率 | 控除額 |
|:------------------------:|:----:|:-----:|
| 1,000万円以下 | 10% | — |
| 3,000万円以下 | 15% | 50万円 |
| 5,000万円以下 | 20% | 200万円 |
| 1億円以下 | 30% | 700万円 |
| 2億円以下 | 40% | 1,700万円 |
| 3億円以下 | 45% | 2,700万円 |
| 6億円以下 | 50% | 4,200万円 |
| 6億円超 | 55% | 7,200万円 |

### 3.3 法定相続分

| 相続人構成 | 配偶者 | その他（均等分割） |
|-----------|:------:|:---------:|
| 配偶者 + 子 | 1/2 | 1/2 |
| 配偶者 + 直系尊属 | 2/3 | 1/3 |
| 配偶者 + 兄弟姉妹 | 3/4 | 1/4 |

### 3.4 相続税の計算手順

1. **課税遺産総額** = 遺産総額 − 基礎控除額
2. **各人の法定相続分額** = 課税遺産総額 × 法定相続分割合
3. **各人の速算税額** = 法定相続分額 × 税率 − 控除額（速算表適用）
4. **相続税の総額** = 各人の速算税額の合計
5. **各人の按分税額** = 相続税の総額 × (各人の取得額 / 遺産総額)
6. **2割加算** = 按分税額 × 0.2（第3順位の場合）
7. **配偶者控除** = min(按分税額, 相続税の総額 × min(取得額, max(法定相続分額, 1億6千万円)) / 遺産総額)
8. **納付税額** = 按分税額 + 2割加算 − 配偶者控除

### 3.5 死亡保険金の非課税限度額

```
非課税限度額 = 500万円 × 法定相続人数
```

各相続人の非課税額:
```
非課税限度額 × (その相続人の受取保険金額 / 相続人全体の受取保険金合計)
```

### 3.6 保険金シミュレーションの計算モデル

| シナリオ | 遺産額の調整 | 保険金 |
|---------|:------------|:------|
| 現状（既存のみ） | 遺産額そのまま | 既存契約の保険金のみ |
| 提案（既存＋新規） | 遺産額 − 新規保険料合計 | 全契約の保険金 |

```
課税遺産額 = 調整後遺産額 + (保険金合計 − 非課税額) − 基礎控除
```

### 3.7 贈与税の計算（特例贈与税率）

| 基礎控除後の課税価格 | 税率 | 控除額 |
|:------------------:|:----:|:-----:|
| 200万円以下 | 10% | — |
| 400万円以下 | 15% | 10万円 |
| 600万円以下 | 20% | 30万円 |
| 1,000万円以下 | 30% | 90万円 |
| 1,500万円以下 | 40% | 190万円 |
| 3,000万円以下 | 45% | 265万円 |
| 4,500万円以下 | 50% | 415万円 |
| 4,500万円超 | 55% | 640万円 |

```
贈与税基礎控除: 110万円/年/受贈者
課税価格 = 年間贈与額 − 110万円
贈与税額 = 課税価格 × 税率 − 控除額
```

### 3.8 現金贈与シミュレーションの計算モデル

| シナリオ | 遺産額 | 贈与の扱い |
|---------|:------|:----------|
| 現状（贈与なし） | 遺産額そのまま | なし |
| 提案（贈与あり） | 遺産額 − 総贈与額 | 贈与税を別途計算 |

```
総負担 = 相続税 + 贈与税合計
納税後財産額 = 遺産額 − 総負担
```

### 4.5 分割シミュレーション

```typescript

  acquisitions: number[];  // 各相続人の取得額
  finalTaxes: number[];    // 各相続人の最終税額
  totalFinalTax: number;   // 税額合計
  isBase: boolean;         // 基準行フラグ
}

interface SplitSimulationResult {
  estateValue: number;
  basicDeduction: number;
  taxableAmount: number;
  totalTax: number;         // 相続税の総額（固定）
  heirLabels: string[];
  legalRow: SplitSimulationRow;  // 法定相続分行
  rows: SplitSimulationRow[];
}
```

## 6. 印刷仕様

| ページ | 用紙サイズ | 備考 |
|--------|-----------|------|
| 相続税計算 | A4 横向き | 2ページ構成（結果+過程+相続人別 / 累進内訳+速算表） |
| 1次2次比較 | A4 横向き | 比較テーブル + 詳細パネル |
| 保険金 | A4 横向き | サマリー / フロー / 相続人別で改ページ |
| 現金贈与 | A4 横向き | サマリー + フロー + 内訳 + 年次比較 |
| 賃貸不動産 | A4 横向き | 計算条件・評価式・比較表を1枚に収める（余白 10mm×12mm） |
| 分割シミュレーション | A3 横向き | サマリー + 凡例 + 結果テーブル |
| 税務タイムライン | A3 横向き | 前提条件 + サマリー + 比較表 |
| 早見表 | A3 横向き | 税額一覧 / 加重平均税率 / 速算表で改ページ |

既定の `@page` は A3 横（余白 1cm）で、A4 横のページは `printClassName`（`calculator-print` 等）に名前付きページを割り当てて上書きしている。

### 印刷時の処理

- `no-print` クラス: 入力エリア・ボタン等を非表示
- `print-only` / `print-only-block`: PrintHeader 等を表示
- `print-page-break`: セクション間の改ページ
- アニメーション無効化（`result-fade-in`）
- shadow / border-radius / padding の縮小
- overflow: visible 強制（テーブル切れ防止）

## 8. 非機能要件

### パフォーマンス

- 画面の計算はクライアントサイドで即座に実行（サーバー通信なし。サーバーは配信と外部向け API だけ）
- コンポーネントの memo 化（HeirSettings 等）
- useMemo / useCallback による再計算抑制

### アクセシビリティ

- Radio ボタン: `role="radiogroup"` + `aria-label` + `aria-describedby`
- アイコン: `aria-hidden="true"`
- フォーカスリング: `focus:ring-2 focus:ring-green-500`

### ブラウザ対応

- number input spinner 非表示（CSS）
- `-webkit-overflow-scrolling: touch`（モバイルスクロール）
- スクロールバー非表示（ナビゲーション）
