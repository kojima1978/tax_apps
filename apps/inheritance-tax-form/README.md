# Inheritance Tax Form（相続税の申告書 第1表）

相続税の申告書「第1表」「第1表（続）」を画面上で作成・印刷するWebアプリケーション。
国税庁様式（令和6年1月分以降用・R8.7）の罫線をそのまま再現し、A4縦1枚に収まる形で印刷できる。

現在はフロントエンドのみ（バックエンド・DBなし）。入力内容はブラウザの localStorage に保存する。

## 画面構成

```
ツールバー（印刷されない）
  財産を取得した人 −/＋ ・ JSON保存 ・ JSON読込 ・ 印刷 ・ クリア
    ↓
第1表        … 被相続人＋「各人の合計」列＋財産を取得した人1人目
第1表（続）  … 2人目以降を2人ずつ。人数に応じて自動で増減（最大21人＝続10枚）
```

## 様式の再現方式（GridForm）

背景画像を敷かず、**罫線そのものを CSS グリッドで引く**。stock-valuation-form と同じ方式。

- セルは `{ top, left, width, height }` を**パーセント**で宣言する（`src/forms/*.ts`）
- `snapLines()` が誤差 0.3% 以内の罫線をまとめ、`grid-template-columns/rows` を `fr` で生成する
- 文字サイズは `fitFontSize()` が枠の実寸から算出して自動で縮める。
  様式は同じ幅の枠に文字数の違うラベルを詰め込むため、文字数だけで決めると
  「算出税額（第３表⑬）」のような長いラベルが枠からはみ出す
- 縦書きの帯（「この申告書が修正申告書である場合」等）は `writing-mode` で表現する

セルの生成は `src/forms/geometry.ts` にまとめてある。人ごとの列（`personColumn`）、
被相続人の列（`decedentColumn`）、①〜㉗の行（`calcRows`）はすべてここのファクトリが返すので、
第1表と第1表（続）で同じ定義を共有できる。

## フィールド名の規約

`GridForm` は `g(field)` / `u(field, value)` の2関数だけで値をやり取りする。
保存先は接頭辞で振り分ける（`useFormData` の `splitField`）。

| 接頭辞 | 保存先 |
|--------|--------|
| `c.` | 共通欄（被相続人・提出先・⑦・Ⓑ） |
| `t.` | 「各人の合計」列（自動集計・書き込み不可） |
| `h0.` `h1.` … | 財産を取得した人 N番目 |

## 自動計算

自動計算は `src/lib/calc.ts` に閉じている。

| 欄 | 算式 |
|----|------|
| ④ 純資産価額 | ①＋②−③（赤字は0） |
| ⑥ 課税価格 | ④＋⑤（1,000円未満切捨て） |
| ⑧ あん分割合 | 各人の⑥ ÷ Ⓐ（小数2位）。**端数調整のため手入力で上書き可**（空に戻すと自動へ復帰） |
| ⑨ 算出税額 | ⑦ × ⑧（円未満切捨て） |
| ⑮ 計 | ⑫＋⑬＋⑭ |
| ⑯ 差引税額 | ⑨＋⑪−⑮（⑩が記入されていれば⑩＋⑪−⑮。赤字は0） |
| ⑲ 小計 | ⑯−⑰−⑱（黒字は100円未満切捨て） |
| ㉑ / ㉒ | ⑲−⑳ が黒字なら㉑、赤字なら㉒（還付） |
| ㉖ 小計の増加額 | ⑲−㉓ |
| ㉗ 納付／還付 | （㉑又は㉒）−㉕（還付は△。黒字は100円未満切捨て） |
| 「各人の合計」列 | 各行の横計。Ⓐは⑥の合計、⑧の合計欄は様式どおり `1.00` 固定 |

**手入力欄**（第2表からの転記のため自動計算しない）:

- Ⓑ 遺産に係る基礎控除額（第2表②の㋩）
- ⑦ 相続税の総額（第2表⑧）
- 法定相続人の数

**単位の扱い**: 様式に「000」「00」があらかじめ印字されている欄（⑥・Ⓑ・⑦・⑰・⑳・㉑・㉔）は
上位桁だけを状態に持ち、計算時のみ `SCALE` 倍して円に戻す。表示・保存が様式の記載と一致する。

**空欄の扱い**: 算式に使う欄が1つも埋まっていない行は 0 ではなく空欄のままにする（白紙の様式を0で埋めない）。

## 入力補助

- 生年月日の元号（1:明治〜5:令和）と続柄（01:配偶者、11:長男 …）は記載要領等のコードから選択式（`src/data/codes.ts`）
- 「※」の付いた欄（※通信日付印の年月日・※確認・※申告期限延長日）は記入不要のため入力欄を置いていない
- 入力は変更のたびに localStorage（`inheritance-tax-form:v1`）へ保存される
- JSON保存／読込でファイルとしても持ち出せる

## 印刷

`window.print()` を呼ぶだけ。`@media print` でツールバーと注記を落とし、
1ページ＝A4縦1枚（209.9 × 297.0mm）に収まることを確認済み。

```
src/
├── App.tsx                     # ページ構成・ツールバー・第1表（続）の枚数制御
├── main.css                    # 様式・印刷レイアウト
├── components/ui/
│   ├── GridForm.tsx            # セル定義 → CSSグリッド。文字サイズ自動調整
│   └── printContext.ts
├── forms/
│   ├── geometry.ts             # セル生成のファクトリ（列・行・帯）
│   ├── table1.ts               # 第1表のセル定義
│   └── table1cont.ts           # 第1表（続）のセル定義

└── data/codes.ts               # 元号コード・続柄コード
```
