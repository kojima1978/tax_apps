# 譲渡所得税 計算ツール

不動産（土地・建物）および株式等の譲渡にかかる所得税・復興特別所得税・住民税を試算するツールです。
いずれも分離課税なので、他の所得とは切り離して計算します。

## 機能

- **タブ切替**: 「不動産」と「株式等」で計算体系が異なるため、入力欄・結果表示ごと分離
- **算式に沿った入力**: 不動産タブの入力欄は「売却の情報 → 取得費 → 譲渡費用 → 特例の適用」の順。譲渡所得の算式（譲渡価額 − 取得費 − 譲渡費用）の3項がそのままセクションになっている
- **譲渡費用の内訳入力**: 仲介手数料・印紙税・測量費・建物取壊費用・その他の5項目に分けて入力し、合計を自動計算。内訳は結果表と印刷物にも残る
- **長期／短期判定**: 譲渡した年の**1月1日時点**の所有期間で自動判定（譲渡日基準ではない）
- **減価償却の自動計算**: 非事業用建物は構造を選ぶだけで償却費相当額を算出（旧定額法・取得価額の95%が上限）。事業用は償却費累計額を手入力
- **概算取得費**: 取得費が不明な場合の5%概算。実額より概算が有利なときは結果画面で指摘
- **主要な特例**: 居住用財産の3,000万円特別控除 / 所有期間10年超の軽減税率（6,000万円以下14.21%）/ 相続財産を譲渡した場合の取得費加算
- **手取り概算**: 譲渡価額 − 譲渡費用 − 税額
- **ミニマムタックス判定**: 基準所得金額が3億3,000万円を超える場合の追加課税（措法41条の19・令和7年分以後）。該当者は稀なのでチェックボックスで開く方式
- **参考資料**: 税率一覧・非事業用建物の償却率表・ミニマムタックスの概要
- **印刷対応**: A4印刷レイアウト（1P: 入力、2P: 計算結果、3P: 参考資料。ミニマムタックスは判定を有効にしたときだけ印刷。会社情報・担当者・作成日フッター付き）

## 税額計算ロジック

| 項目 | 計算方法 |
|:-----|:---------|
| 譲渡所得金額 | 譲渡価額 − （取得費 + 取得費加算額） − 譲渡費用 |
| 取得費（実額） | 土地の取得価額 + 建物の取得価額 − 償却費相当額 |
| 取得費（概算） | 譲渡価額 × 5% |
| 償却費相当額（非事業用） | 建物の取得価額 × 0.9 × 旧定額法の償却率 × 経過年数（取得価額の95%が上限） |
| 経過年数 | 取得日〜譲渡日。6ヶ月以上の端数は1年に切上げ |
| 課税譲渡所得金額 | 譲渡所得金額 − 特別控除（居住用財産 最大3,000万円） |
| 長期譲渡（所有期間5年超） | 所得税15% + 復興0.315% + 住民税5% = 20.315% |
| 短期譲渡（所有期間5年以下） | 所得税30% + 復興0.63% + 住民税9% = 39.63% |
| 軽減税率（居住用・10年超） | 6,000万円以下の部分: 所得税10% + 復興0.21% + 住民税4% = 14.21%<br>6,000万円超の部分: 長期譲渡の税率 |
| 株式等 | 所得税15% + 復興0.315% + 住民税5% = 20.315%（上場・一般とも同率） |
| 復興特別所得税 | **所得税額 × 2.1%**（譲渡所得に直接掛けない） |

### ミニマムタックス（極めて高い水準の所得に対する課税・措法41条の19）

令和7年分以後の所得税に適用。分離課税の譲渡所得は税率が低いため、所得が大きいほど負担率が下がる
（いわゆる「1億円の壁」）ことへの是正措置。

| 項目 | 計算方法 |
|:-----|:---------|
| 基準所得金額 | 課税譲渡所得金額（特別控除**後**）+ その他の合計所得金額 |
| 基準所得税額 | 譲渡所得に対する所得税額 + その他の所得に対する所得税額（いずれも**復興特別所得税を含まない**／外国税額控除の適用前） |
| 追加納付額 | （基準所得金額 − 3億3,000万円）× 22.5% − 基準所得税額（プラスの場合のみ） |
| 復興特別所得税 | 追加納付する所得税額 × 2.1% |
| 住民税 | 影響しない（追加課税は所得税のみ） |

判定は不動産タブ・株式等タブの結果を**合算**して行う（基準所得金額はその年の全所得の合算のため）。
適用年分の判定には不動産タブの譲渡日を使い、未入力の場合は本年とする。

### 対象外（本ツールでは扱わない）

譲渡損失の損益通算・繰越控除、買換え特例、空き家の3,000万円特別控除、収用等の特別控除、
総合課税となる資産（ゴルフ会員権・書画骨とう等）の譲渡。

## 技術スタック

- **ビルドツール**: Vite 6
- **ランタイム**: React 19 + TypeScript 5
- **スタイリング**: Tailwind CSS v4 (`@tailwindcss/postcss`)
- **Docker**: 共通 `docker/Dockerfile.vite-static`

## Docker

### 単体起動

```bash
docker compose up -d             # 起動
docker compose up -d --build     # 再ビルド
docker compose logs -f           # ログ確認
docker compose down              # 停止
```

アクセス: http://localhost:3019/capital-gains-calc/

> 事前に `docker network create tax-apps-network` でネットワークを作成しておく必要があります。

### manage.sh 経由

```bash
docker/scripts/manage.sh build capital-gains-calc   # 再ビルド
docker/scripts/manage.sh logs capital-gains-calc    # ログ確認
```

Gateway 経由アクセス: http://localhost/capital-gains-calc/
