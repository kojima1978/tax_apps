# Asset Valuation（相続税 減価償却資産評価）機能仕様書

## 1. 概要

相続税申告における減価償却資産の評価額を算出するWebアプリケーション。
会計ソフトから出力されたCSVファイルを取り込み、相続税法の評価通達に基づいて計算し、Excel出力・印刷を行う。

### 1.1 技術スタック

| 項目 | 技術 |
|------|------|
| フロントエンド | Vite 7.x + React 19.x + TypeScript 5.x |
| スタイリング | Tailwind CSS v4（@tailwindcss/postcss） |
| アイコン | lucide-react |
| Excel出力 | xlsx-js-style |
| テーマカラー | 緑（#2e7d32） |
| Docker ポート | 3017 |
| basePath | `/asset-valuation` |

### 1.2 アーキテクチャ

- **完全フロントエンド**（バックエンド不要）
- 未償却残高表はJSONデータとして内蔵（H24.4.1以後取得分）
- CSV解析はブラウザ内で完結（最大300件）
- データ永続化: JSON入出力（案件データ・マッピングプリセット）
- Docker: Vite dev → nginx:1.27-alpine 静的配信

## 2. 画面仕様

### 2.1 画面構成

単一ページ・ステップ形式（4ステップ）

```
Step 1: CSVインポート + 基本情報入力
    ↓
Step 2: カラムマッピング
    ↓
Step 3: データ確認・編集
    ↓
Step 4: 計算結果 → Excel出力 / 案件JSON保存 / マッピングJSON出力
```

ステップ間は「次へ」「戻る」ボタンで遷移。各ステップにバリデーションあり。

### 2.2 Step 1: CSVインポート + 基本情報入力

| 項目 | 仕様 |
|------|------|
| 案件名 | テキスト入力（必須）。例：「株式会社〇〇〇 様」 |
| 課税時期 | 日付入力（必須） |
| CSVファイル | ファイルドロップ or ファイル選択 |

#### CSV要件
- ヘッダー行あり（1行目）
- 最大300件の資産データ

### 2.3 Step 2: カラムマッピング

CSVのカラムを、計算に必要なフィールドへマッピングする画面。

#### 2.3.1 必須マッピングフィールド

| フィールド | 説明 | 型 |
|-----------|------|------|
| 資産カテゴリ | 建物/建物付属設備/構築物/機械装置/車両/器具備品 | テキスト |
| 資産名称 | 減価償却資産の名称等 | テキスト |
| NO | 管理番号 | 数値 |
| 取得年月 | 取得日（日付 or Excelシリアル値） | 日付 |
| 耐用年数 | 法定耐用年数 | 数値 |
| 取得価額 | 取得時の価額 | 数値 |
| 期末簿価 | 直近期末の帳簿価額 | 数値 |

#### 2.3.2 マッピングUI

- CSVの先頭5行をプレビュー表示
- **CSVヘッダー名から7フィールドを自動割り当て**（`autoMapColumns`）。割り当てたフィールドには「自動」バッジを表示し、
  ユーザーがプルダウンを変更するとバッジは消える
  - 別名辞書 `COLUMN_ALIASES` で照合。全角英数・空白を正規化してから「完全一致 → 部分一致」の2段で判定
  - 完全一致を全フィールドで先に確定させるため、`取得年月日` が `取得価額` の枠を奪うことはない
  - 1つのCSVカラムは1フィールドにしか割り当てない
  - 発火はヘッダー構成が変わった初回のみ、かつ**全フィールドが未割り当てのとき**だけ（Step 3から戻っても編集内容を壊さない）
  - プリセット読込時は「自動」バッジをリセット
- 各フィールドにドロップダウンでCSVカラムを割り当て（自動割り当ての修正もここで行う）
- ドロップダウン変更時、プレビューが即座に更新
- 未マッピングの必須フィールドは赤色で警告

#### 2.3.3 マッピングプリセット

| 機能 | 仕様 |
|------|------|
| 保存先 | localStorage + JSON入出力 |
| 保存 | 現在のマッピングに名前を付けて保存 |
| 読込 | 保存済みプリセットをドロップダウンで選択→即適用 |
| 削除 | 不要なプリセットを削除 |
| JSONエクスポート | プリセットをJSONファイルとしてダウンロード |
| JSONインポート | JSONファイルをアップロードしてプリセットを追加 |

#### 2.3.4 カテゴリ名の正規化

CSVの資産カテゴリ値を、アプリ内部の40カテゴリ（**資産区分16 × 償却方法**）にマッピングする。

**資産区分 → 選択できる償却方法**

| 資産区分 | 償却方法 | CSVでの表現例 |
|---------|---------|-------------|
| 建物 | 定額法 / 旧定額法 / 旧定率法 | 建物、たてもの |
| 建物附属設備 | 定額法 / 200%定率法 / 250%定率法 / 旧定額法 / 旧定率法 | 建物付属設備、建物附属設備、付属設備 |
| 構築物 | 同上（5種） | 構築物 |
| 機械及び装置 | 同上（5種） | 機械装置、機械及び装置 |
| 車両運搬具 | 同上（5種） | 車両、車両及び運搬具、車両運搬具 |
| 工具器具備品 | 同上（5種） | 器具備品、器具及び備品、工具器具備品 |
| 生物 | 定額法 / 旧定額法 / 旧定率法 | 生物 |
| ソフトウェア | 定額法 | ソフトウェア、ソフトウエア |
| 特許権 / 商標権 / 意匠権 / 実用新案権 | 定額法 | 同名 |
| のれん | 定額法 | のれん、営業権 |
| 一括償却資産 | 3年均等 | 一括償却資産、一括償却 |
| 少額減価償却資産 | 即時償却 | 少額減価償却資産、少額資産 |
| 繰延資産 | 均等償却 | 繰延資産、創立費、開業費、開発費、株式交付費、社債発行費 |

- カテゴリ名は `資産区分（償却方法）` 形式（例: `建物附属設備（200%定率法）`）
- **繰延資産（均等償却）は財産性なし**（評価額0・評価根拠「財産性なし」）。帳簿の繰延資産を明細に載せて突合するための区分
- **償却方法は帳簿上の分類**であり、相続税評価の計算には影響しない（→ 3.3）
- 自動マッチングは「区分名のみ」「`区分（償却方法）`」「`区分（連番）`」のいずれにも対応。
  償却方法が特定できない場合は既定値（有形資産は200%定率法、建物・生物・無形は定額法）を採用
- 未マッチの値はユーザーが手動で割り当て
- **未マッチの値には近い資産区分を候補提示**（`suggestAssetClasses`）。別名辞書との最長共通部分列で類似度を出し、
  0.4以上の上位3件をボタン表示。クリックでその区分の既定カテゴリを割り当てる（例: `工具備品` → `工具器具備品`）
- **選択UIは2段プルダウン**（資産区分 → 償却方法）。償却方法が1つしかない区分では2段目を非活性化
- カテゴリマッピングもプリセットに含めて保存

##### レガシーカテゴリ

`無形固定資産` は**旧バージョンの案件JSONを読み込むためだけに残している**（新規選択不可）。
旧カテゴリ名（`建物付属設備` / `機械装置` / `車両` / `器具備品` 等）は案件JSON読込時に新カテゴリへ自動移行する。
旧カテゴリの `繰延資産` は選択可能な `繰延資産（均等償却）` へ移行する（評価額の扱いは同じ＝財産性なし）。

## 3. 計算仕様

### 3.1 共通計算

#### 3.1.1 経過年数

```
経過年数 = ROUNDUP((課税時期 - 取得年月) / 365, 0)
```

- 1年未満の端数は1年に切り上げ

#### 3.1.2 3年以内判定

```
3年以内 = 取得年月 > (課税時期 - 365 × 3)
```

- 該当カテゴリ: 建物、建物附属設備、構築物

### 3.2 カテゴリ別計算ルール

計算は**資産区分ごと**に決まる。カテゴリ名に含まれる償却方法は計算に影響しない（→ 3.3）。

#### 3.2.1 建物

| 条件 | 評価根拠 | 計算式 |
|------|---------|--------|
| 固定資産税評価明細あり | 評基通89 | 相続税評価額 = `-`（対象外） |
| 3年以内取得 | 3年内簿価 | 相続税評価額 = 期末簿価 |
| 上記以外 | 評基通89-2(2) | 相続税評価額 = `(取得価額 - 償却額) × 0.7` |

**賃貸の場合（建物）:** 上記で算出した相続税評価額に対し、さらに `× 0.7`（借家権割合30%控除）を適用。
固定資産税評価明細の行（評価額 = `-`）には適用しない。

**建物の償却額（定額法）:**

```
経過年数 ≧ 耐用年数の場合:
  償却額 = 取得価額 × 0.9

経過年数 < 耐用年数の場合:
  償却額 = 取得価額 × 0.9 × (経過年数 / 耐用年数)
```

**判定優先順位:** 固定資産税評価明細 > 3年以内 > 89-2(2)

#### 3.2.2 建物附属設備

| 条件 | 評価根拠 | 計算式 |
|------|---------|--------|
| 固定資産税評価明細あり | 評基通89 | 相続税評価額 = `-`（対象外） |
| 3年以内取得 | 3年内簿価 | 相続税評価額 = 期末簿価 |
| 上記以外 | 評基通92 | 相続税評価額 = `ROUNDDOWN(取得価額 × 未償却残額割合 × 0.7, 0)` |

**賃貸の場合（建物附属設備）:** 上記で算出した相続税評価額に対し、さらに `× 0.7`（借家権割合30%控除）を適用。
固定資産税評価明細の行（評価額 = `-`）には適用しない。

#### 3.2.3 構築物

| 条件 | 評価根拠 | 計算式 |
|------|---------|--------|
| 3年以内取得 | 3年内簿価 | 相続税評価額 = 期末簿価 |
| 上記以外 | 評基通97 | 相続税評価額 = `ROUNDDOWN(取得価額 × 未償却残額割合 × 0.7, 0)` |

#### 3.2.4 機械及び装置 / 車両運搬具 / 工具器具備品 / 生物 / ソフトウェア

| 評価根拠 | 計算式 |
|---------|--------|
| 評基通129 | 相続税評価額 = `ROUNDDOWN(取得価額 × 未償却残額割合, 0)` |

#### 3.2.5 特許権 / 商標権 / 意匠権 / 実用新案権 / のれん / 一括償却資産 / 少額減価償却資産

| 評価根拠 | 計算式 |
|---------|--------|
| 簿価 | 相続税評価額 = 期末簿価 |

#### 3.2.6 繰延資産（均等償却）／無形固定資産（レガシー）

| 評価根拠 | 計算式 |
|---------|--------|
| 財産性なし | 相続税評価額 = 0 |

### 3.3 未償却残額割合

**定率法未償却残額表（平成24年4月1日以後取得分＝200%定率法）** を使用。

```
未償却残額割合 = rateTable[経過年数][耐用年数]
```

- 経過年数 ≧ 耐用年数の場合: 未償却残額割合 = 0
- 経過年数 ≦ 0 の場合: 未償却残額割合 = 1
- テーブル範囲: 経過年数 1〜50、耐用年数 3〜50（耐用年数2の列は表に存在せず、割合0として扱う）

#### 3.3.1 償却方法と控除額の関係（重要）

> この通達の適用にあたり、評価を行う時点において効力を有する「耐用年数省令 別表第十（定率法償却率表）」の
> 最新の定率法（＝200%定率法）を**一律で適用**して控除額を計算するのが財産評価の原則的な取扱いとなります。

したがって、カテゴリ名に含まれる `250%定率法` / `旧定率法` / `旧定額法` は**帳簿上の分類を表すラベル**であり、
アプリの控除額計算では全ての定率法系カテゴリに上記の200%定率法表を適用する。
これらのカテゴリを分けている目的は、**小計を帳簿と突合しやすくすること**にある。

## 4. Excel出力仕様

### 4.1 レイアウト

sample.xlsmの「減価償却資産」シートを再現する。

```
行1: 案件名（「株式会社〇〇〇　様」）
行2: 課税時期（日付値・和暦書式）
行3: 3年以内（日付値・和暦書式）
行4: （空行）
行5: 【カテゴリ名】
行6: ヘッダー行（NO, 名称, 取得年月, 課税時期, 経過年数, 耐用年数, 取得価額, 償却額/残価率, 相続税評価額, 期末簿価, その他）
行7〜: データ行
行N: 合計行（取得価額合計, 相続税評価額合計, 期末簿価合計）
（空行）
次のカテゴリ...
（全カテゴリ終了後）
評価通達条文テキスト
```

日付セル（`B2` 課税時期 / `B3` 3年以内 / データ行の取得年月・課税時期）は `dateCell()` で出力する。
**値は日付**（`t: 'd'`）で表示書式だけを和暦 `[$-ja-JP-x-gannen]gee"."mm"."dd`（例: `R05.07.02`）にしているので、
Excel側で `DATEDIF` や差分計算にそのまま使える。文字列で書き出すと計算に使えなくなるため行わない。
Excelプレビュー（画面）は他の日付にそろえて西暦表記のまま。

### 4.2 シート構成

| シート | 内容 |
|--------|------|
| 減価償却資産 | 本表（カテゴリ別セクション + 小計 + 末尾に評価通達条文テキスト） |
| 計算根拠 | 資産1件ごとの一覧（NO / 資産名称 / 評価額 / 計算根拠） |
| 残価率表 | 定率法未償却残額表のマトリクス（経過年数50行 × 耐用年数48列、`A1:AW54`） |

減価償却資産・計算根拠の**カテゴリセクションの並び順は Step 3 の並び順**（`exportToExcel` に `labelOrder` を渡す）。

### 4.3 カラム仕様

| カラム | 建物 | 定率法評価の区分 | 簿価評価の区分 |
|--------|------|----------------|--------------|
| H列 | 償却額（金額） | 残価率（小数3桁） | `-` |

すべての数式セルはキャッシュ値（`v`）と数式（`f`）の両方を持つため、Excelで開いた直後から値が表示される。

| 列 | 数式 |
|----|------|
| H列（建物） | `IF(E>=F,G*0.9,G*0.9*(E/F))` |
| H列（定率法） | `IF(E>=F,0,IF(E<=0,1,IFERROR(INDEX('残価率表'!$B$5:$AW$54,MATCH(E,'残価率表'!$A$5:$A$54,0),MATCH(F,'残価率表'!$B$4:$AW$4,0)),0)))` |
| I列（建物） | `ROUNDDOWN((G-H)*0.7[*0.7],0)` |
| I列（定率法） | `ROUNDDOWN(G*H[*0.7][*0.7],0)` |
| I列（簿価/3年内） | `J` |
| 小計行 | `SUM(列start:列end)` |

**残価率表シートの目的**: ユーザーが適用された残価率を表で確認できるようにするため。
本表H列は INDEX/MATCH でこのシートを参照するので、経過年数・耐用年数を書き換えると Excel 側で再計算される。
表は素のマトリクスとして出力し、使用セルの強調は行わない。

### 4.4 書式

| 要素 | 書式 |
|------|------|
| フォント | MS ゴシック, サイズ10 |
| ヘッダー行 | 背景色(#D9E1F2)付き、太字、上下横線のみ（縦線なし） |
| データ行 | 罫線なし |
| 金額 | 3桁カンマ区切り、右寄せ |
| 日付 | YYYY/MM/DD |
| 合計行 | 太字、A列から全列に上横線 |
| 評価額 `-` | 中央寄せ |
| 列幅 | `!cols` で指定（出力に反映される） |
| 余白 | 狭め（`!margins` で指定、出力に反映される） |
| ファイル名 | `{案件名}_減価償却資産評価_{YYYYMMDD}.xlsx` |

> **既知の制限（xlsx-js-style 1.2.0）**
> コード上は `!pageSetup`（A4横・全列1ページ幅）と `!headerFooter`（フッターのページ番号 `&C&P / &N`）を
> 設定しているが、このライブラリは `<pageSetup>` / `<headerFooter>` / ウィンドウ枠固定の `<pane>` を
> **xlsx へ書き出さない**。したがって印刷設定とフッターは出力ファイルには入っておらず、
> 横向き・1ページ幅はExcel側で都度設定する必要がある。書き出されるのは `!cols` / `!margins` / `!merges` のみ。
> このため Step 4 の出力ボタン下に、Excelでの設定手順（［ページレイアウト］→［印刷の向き: 横］／
> ［拡大縮小: すべての列を1ページに印刷］）を案内する注記を出している。

### 4.5 評価通達条文

Excel末尾に以下の条文テキストを記載:

- 評基通89-2（文化財建造物である家屋の評価）
- 評基通92（附属設備等の評価）
- 評基通97（構築物の評価）
- 評基通128〜130（一般動産の評価・償却費の額の計算）
