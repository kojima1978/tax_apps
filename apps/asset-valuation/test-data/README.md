# テストデータ

http://localhost/asset-valuation/ の動作確認用サンプル。
**課税時期は `2026-07-01` を入力する前提**で作ってある（「3年以内取得」判定がこの日付基準）。

| ファイル | 用途 |
|---------|------|
| `sample-assets.csv` | 標準サンプル。UTF-8(BOM付) / 24行 / 全16資産区分をカバー。NOは4桁（1001〜1024） |
| `sample-assets-cp932.csv` | 上と同内容の CP932(Shift_JIS)版。エンコーディング自動検出の確認用 |
| `sample-assets-edge.csv` | 表記ゆれ・和暦・Excelシリアル値などのエッジケース / 15行。NOは4桁/5桁/6桁を混在 |
| `asset-valuation-test-case.json` | 計算済みの案件JSON。Step 1 の「案件JSONインポート」で復元 |

## 使い方

1. Step 1 で案件名（例:「サンプル商事株式会社 様」）と課税時期 `2026-07-01` を入力し、CSVを選択
2. Step 2 はヘッダー名が別名辞書に一致するので**7項目すべてに「自動」バッジが付く**（そのまま次へ）
3. Step 3 でカテゴリ判定・3年以内バッジを確認
4. Step 4 で計算結果とExcel出力を確認

## sample-assets.csv が確認できること

- ヘッダーの自動割り当て（`管理番号` / `勘定科目` / `資産の名称等` / `取得年月日` / `耐用年数` / `取得価額` / `期末帳簿価額`）
- 「区分（償却方法）」形式のカテゴリ自動判定（40カテゴリすべての解決経路）
- 評価方式の4系統: 定額法×0.9（建物）/ 定率法残価率（附属設備・構築物・機械・車両・器具備品）/ 簿価（無形固定資産・一括償却・少額）/ 評価額0（繰延資産）
- 3年以内取得の自動ハイライト … No.1003(2025/09/01)、No.1012(2024/12/10)、No.1023(2025/05/20)
- 帳簿上の償却方法ちがいの小計分割 … 建物附属設備が 定額法／200%／250% の3グループに分かれる
- NOの桁数（4桁）… 会計ソフトの管理番号は4桁以上が普通なので、画面・Excelの桁あふれを確認する
- 簿価0の資産（No.1020・1021・1024）と簿価1円の資産（No.1023）

手動で切り替えて確認する項目:
- **固定資産税評価明細** … No.1001 をONにすると評価額が空欄（明細から転記する運用）になる
- **賃貸控除(×0.7)** … No.1001 や No.1004 をONにして借家権割合30%控除を確認
