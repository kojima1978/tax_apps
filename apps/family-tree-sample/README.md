# 相続関係管理 — 家系図作成サンプル

Docker で動く、外部依存のない日本語のサンプルアプリです。

## 起動

このディレクトリで `docker compose up -d --build` を実行し、http://localhost:5180 を開きます。停止は `docker compose down`。既存アプリとは独立した構成です。

## 機能

- 被相続人1人・配偶者1人・子・孫、および父母・兄弟姉妹・その他の親族や関係者の登録（最大30人）
- 人物の追加、編集、削除、関係線の自動配置
- 家系図の拡大・縮小、倍率表示、100%リセット、画面サイズに合わせた全体表示。拡大時は上下左右にスクロール可能。SVGは表示倍率に左右されず元の寸法で保存
- ブラウザへの自動保存、JSONバックアップ／復元、SVG出力
- 法定相続情報一覧図の下書きプレビュー、A4印刷／ブラウザのPDF保存
- 申出人、作成日、相続人住所の表示選択
- 人物ごとの出力対象選択（被相続人は必須）、家系図の全員／選択表示、表示範囲のSVG保存
- 法務局公開様式の文面に基づく委任状作成、登録済み代理人の情報反映、委任日・交付通数入力
- 一覧図／委任状の個別印刷、2文書の一括印刷

サンプルの人物・住所は架空です。データはこのブラウザのlocalStorageに保存します。別の端末・ブラウザとは共有しません。ブラウザのデータ削除で消えるためJSONを保管してください。バックアップにも個人情報が含まれます。

## 一覧図出力の範囲

選択した生存する配偶者・子の合計5人までを対象にした下書きです。「人物情報」のチェックで出力対象を変更できます。未選択の配偶者・子がいる場合は確認メッセージを表示します。提出用一覧図には法定相続人全員を記載してください。

被相続人・配偶者に関連付けた父母（各2人まで）、被相続人の兄弟姉妹、兄弟姉妹に関連付けて続柄を「姉の子」「兄の子」「弟の子」「妹の子」とした人物は世代ごとに関係線で表示します。それ以外の関係者は別枠で表示します。被相続人・配偶者・子以外は生年月日なしでも登録可能です。

サンプルは11人です。被相続人・妻・子3人に加え、被相続人の父母、姉、姉の子、妻の父母を登録しています。追加した6人は初期状態では一覧図の出力対象外です。保存済みデータをサンプルに置き換える場合は「サンプルに戻す」を使用してください。

家系図はマウスの左ボタンでドラッグして表示位置を移動できます。人物はクリックで編集、ドラッグでは画面を移動します。「全体表示」で中央に戻せます。

家系図の選択表示・SVG保存はすべての登録区分に対応します。一覧図は孫や父母・兄弟姉妹・関係者を出力対象に選んだ場合、および死亡した配偶者・子を含む構成では出力を止めます。生存する子の子である孫は、一覧図の対象外として登録できます。代襲相続、数次相続、複数婚姻などを自動処理する機能はありません。法定相続人の資格・範囲を自動判定するアプリではありません。続柄は戸籍に従って手動入力し、提出前に戸籍等と照合してください。

委任状は法務局の公開Word様式（001397601.docx）の委任事項・項目をHTMLで再現しています。原本のWordファイルそのものの編集ではありません。代理人は登録済み人物または直接入力から指定します。委任者は一覧図の申出人と共通です。委任事項を自動で変更・追加する機能はありません。委任者本人による確認後に使用してください。

印刷はA4縦、倍率100%、ヘッダーとフッターをオフに設定してください。
