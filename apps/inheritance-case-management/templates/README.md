# テンプレートフォルダ

見積書・請求書・請求書発行依頼票の Excel テンプレートをこのフォルダに配置します。

## ファイル名

| ファイル名 | 用途 |
|---|---|
| `estimate_template.xlsx` | 見積書・請求書共通テンプレート |
| `invoice_request_template.xlsx` | 請求書発行依頼票テンプレート |

見積書・請求書は共通の `estimate_template.xlsx` を使用します。請求書出力時はコード側でタイトル、金額ラベル、振込先などを上書きします。

請求書発行依頼票は、案件データの担当者・請求先（被相続人名付き）・紹介者・売上と紹介料の内訳・報酬額・立替金をセルに転記します（後述の「請求書発行依頼票の転記セル」）。

## 見積書・請求書テンプレートの転記セル

`estimate_template.xlsx` には、見積書・請求書共通で以下のセルへ転記します。

| 項目 | セル | 備考 |
|---|---:|---|
| 宛名 | D2/D4/D6 | 出力用宛名。見た目は D3/D5/D7 の3枠。見積書・請求書の個別宛先は最大3人まで、氏名を D 列、敬称を H 列へ転記する |
| 発行日 | L3 | 画面で選んだ発行日。テンプレートの `=TODAY()` を上書きする。和暦の表示書式はセル側の設定をそのまま使う |
| 被相続人名 | H15 | 案件の被相続人名 |
| 遺産総額 | H22 | 報酬計算の遺産総額 |
| 土地数（路線価） | K27 | 件数 |
| 土地数（倍率） | K28 | 件数 |
| 非上場株式の数 | K30 | 件数 |
| 相続人の数 | J32 | 人数 |
| 特別業務報酬額 1行目 内容 | B35 | 先頭に半角スペース4つを付与、MS 明朝 9pt 太字 |
| 特別業務報酬額 1行目 金額 | M35 | 金額 |
| 特別業務報酬額 2行目 内容 | B36 | 先頭に半角スペース4つを付与、MS 明朝 9pt 太字 |
| 特別業務報酬額 2行目 金額 | M36 | 金額 |
| 値引額 | M38 | マイナス値で転記。例: 1,000 -> -1,000。M37 はテンプレート側の関数を保持するため上書きしない |
| 差引額（税抜） | M39 | テンプレート側の数式を保持するため上書きしない |
| 立替金合計 | M42 | 請求書のみ転記。見積書では上書きしない |

見積書は案件詳細の「見積書」欄の数字、つまり見積額・見積紹介料を基準に出力します。

請求書と請求書発行依頼票は、案件詳細の「請求書」欄の数字、つまり報酬額・紹介料を基準に出力します。

立替金は請求書と請求書発行依頼票にのみ転記します。見積書では立替金セルを上書きしません。

請求書出力時は `B42` を ` ４．立替金費用（戸籍謄本・不動産登記事項閲覧・残高証明書発行手数料等）` に置き換え、MS 明朝 10pt 太字にします。

## 請求書出力時の上書き

請求書出力時は `estimate_template.xlsx` に対して、以下のセルも請求書用に上書きします。

| セル | 内容 |
|---:|---|
| B11 | 請求書タイトル |
| B14 | 請求文 |
| B17 | 金額ラベル |
| B42 | ` ４．立替金費用（戸籍謄本・不動産登記事項閲覧・残高証明書発行手数料等）` |

| B44 | 振込先ラベル |

## レターヘッドの自動縮小（見積書・請求書）

`estimate_template.xlsx` 右上のレターヘッド（K7:O7〜K10:O10）は、出力時に
コード側（`template-service.ts` の `shrinkLetterheadToFit`）で**入らない行だけ**
フォントサイズを落とします。

| 項目 | 値 |
|---|---|
| 対象セル | K7・K8・K9・K10（いずれも K〜O 列の結合セル・幅225px） |
| 判定 | ＭＳ 明朝が等幅（全角1em・半角0.5em）なので実幅を計算し、使える幅と比べる |
| 使える幅 | 結合幅 − 余白5px の95%（縮小印刷の丸めに対する安全マージン） |
| 落とし方 | 0.5pt 刻み・下限7pt。収まっている行は触らない |

Excel の結合セルは、入り切らない文字を隣のセルへあふれさせず**切り捨てます**
（`shrinkToFit` も結合セルでは効きません）。住所行は9ptでの実幅216pxに対して
使える幅が220pxしか無く、余裕が半角0.3文字分だったため、「1ページに収める」で
93%前後に縮むときの px 丸めや、ＭＳ 明朝が無い環境のフォント代替で末尾が
欠けることがありました。事務所の移転などでテンプレートの文字数が変わっても
効くように、固定のサイズを決め打ちせず毎回実測しています。

テンプレートの列幅や文字数を変えると縮小後のサイズも変わります。計算部分は
`web/src/lib/services/excel-text-fit.ts`、テストは同ディレクトリの
`excel-text-fit.test.ts` と `template-service.test.ts` にあります。

## 請求書発行依頼票の転記セル

`invoice_request_template.xlsx` には以下のセルへ転記します。

| 項目 | セル | 備考 |
|---|---:|---|
| 発行日 | B4 | 画面で選んだ発行日。テンプレートの `=TODAY()` を上書きする |
| 担当者名 | W3 | 案件の担当者。未設定なら上書きしない |
| 請求先 | C5 | 宛名に `（被相続人: ○○）` を付けて転記 |
| 紹介者名 | A18 | 8pt。未設定なら上書きしない |
| 売上・紹介料内訳 | A19 | `売上: n円　紹介料: n円`（売上は報酬額 − 紹介料）。8pt |
| 報酬額（税抜） | V18 | 案件の報酬額 |
| 立替金合計 | H15 | 立替金の合計 |
| 切り取り線 | A20:AB20 | 下端に破線の罫線を引く（後述） |

## 印刷設定

3種すべて、出力時にコード側（`web/src/lib/services/template-service.ts` の `applyPrintSetup`）で
以下を毎回上書きします。テンプレート側の設定は当てにしません。

| 設定 | 値 |
|---|---|
| 用紙 | A4（`paperSize` 9）・縦 |
| 拡大縮小 | 「1ページに収める」（横1×縦1） |
| 倍率 | 見積書・請求書 90% / 依頼票 95%。「1ページに収める」を外したときに使われる値 |
| 印刷範囲 | 見積書・請求書 `A1:O46` / 依頼票 `A1:AB32` |
| 配置 | 水平中央 |
| 余白 | 上下左右 10mm・ヘッダー/フッター 5mm |
| シート名 | 見積書 / 請求書 / 請求書発行依頼票 |

固定倍率に頼らないのは、テンプレートを差し替えたり行が1行増えた時点で破綻するためです。
実際に見積書・請求書は倍率100%固定で、内容（約29.7cm）が印刷領域（約28.2cm）を超えて
縦2ページに割れていました。印刷範囲を明示するのは、書式だけ残った空白行・列
（見積書テンプレートは `AO82` まで書式がある）が白紙の2ページ目を作るのを防ぐためです。

「1ページに収める」と倍率は同時に保存できます（Excel 自身もそうしていて、チェックを
外したときの値として覚えている）。倍率を書かないと 100% 扱いになり、チェックを外した
瞬間に依頼票は横が 7.6mm はみ出して右端3列（Z・AA・AB）が2ページ目へ落ちます。
実寸は 見積書・請求書 175.7 x 297.5mm（縦が制約・93%で収まる）、依頼票 197.6 x 198.0mm
（横が制約・96%で収まる）なので、余裕を見て 90% / 95% を `FALLBACK_SCALES` に入れています。
見積書・請求書は内容の高さ 297.5mm が A4 の紙そのもの（297mm）を超えるため、倍率100%では
余白をゼロにしても1ページには入りません。

### 切り取り線について

依頼票テンプレートの切り取り線は破線の**図形**（`xl/drawings`）ですが、ExcelJS は図形を
書き出せないため生成ファイルからは消えます。同じ位置（行20は空の余白行で罫線も無い）の
下端に破線の罫線を引いて代替しています。テンプレート側で切り取り線の位置を変えたときは
`template-service.ts` の `CUT_LINE_ROW` / `CUT_LINE_LAST_COLUMN` も合わせて直してください。

## 注意

- テンプレートが存在しない場合はエラーになります。必ず配置してください。
- このフォルダ内の Excel ファイルは `.gitignore` で除外されています。
- Docker コンテナ内では `/app/templates/` に読み取り専用でマウントされます。
