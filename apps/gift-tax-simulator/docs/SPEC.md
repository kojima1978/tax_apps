# 贈与税 比較Webアプリ — 仕様書

## 1. 概要

### 1.1 目的
税理士法人マスエージェント向けの業務支援ツール。贈与税・不動産取得税・登録免許税の試算を行い、顧客への説明資料（印刷）として活用する。

### 1.2 対象ユーザー
- 税理士法人の職員
- 顧客への説明時に利用

### 1.3 動作環境
- モダンブラウザ（Chrome, Edge, Firefox, Safari）
- レスポンシブ対応（PC・タブレット・スマートフォン）
- サーバーサイド処理なし（全計算をクライアントサイドで実行）

## 3. 機能仕様

### 3.1 贈与税シミュレーター（`/`）

#### 入力項目

| 項目 | 型 | 必須 | バリデーション | 備考 |
|-----|---|------|-------------|------|
| 贈与金額 | 数値（円） | Yes | 1円〜10億円 | カンマ区切り自動フォーマット、全角→半角変換 |
| 贈与区分 | 選択 | Yes | - | 特例贈与 / 一般贈与 |

#### 出力

| 項目 | 説明 |
|-----|------|
| パターン名 | 一括贈与 / 2年分割 / 4年分割 |
| 1回あたりの贈与額 | 総額 ÷ 分割回数（端数切捨） |
| 1回あたりの税額 | 速算表による計算 |
| 申告回数 | 分割回数 |
| 実効税率 | 1回あたり税額 ÷ 1回あたり贈与額 |
| トータル贈与税額 | 1回あたり税額 × 分割回数 |
| 棒グラフ | トータル贈与税額のパターン間比較 |

#### 空状態
- 未入力・未計算時はアイコンとガイドテキストを表示

#### 操作
- 金額入力 → 区分選択 → 「計算する」ボタン押下
- Enterキーでも計算実行

### 3.4 不動産取得税シミュレーター（`/acquisition-tax`）

#### 入力項目

**共通設定**

| 項目 | 型 | 選択肢/備考 |
|-----|---|------------|
| 登記原因（取引種別） | 選択 | 売買 / 新築 / 相続 / 贈与（既定: 贈与） |
| 計算対象 | トグル | 土地 / 建物（複数選択可） |

**土地の情報**

| 項目 | 型 | 備考 |
|-----|---|------|
| 持ち分 | 分数 | 例: 1/2。課税標準 = 評価額 × 持ち分 |
| 宅地 - 固定資産税評価額 | 数値（円） | 宅地特例（1/2）適用 |
| 宅地 - 面積（m²） | 数値 | 税額軽減計算に使用 |
| その他（宅地以外） - 評価額 | 数値（円） | 特例なし |

**建物の情報**

| 項目 | 型 | 備考 |
|-----|---|------|
| 固定資産税評価額 | 数値（円） | |
| 床面積（m²） | 数値 | 土地の税額軽減にも使用 |
| 持ち分 | 分数 | 例: 1/2 |
| 建築年月日 | 年（テキスト＋候補）/ 月 / 日 選択 | 年は「1985」「昭和60」「S60」のどれでも入る |
| 居住用かどうか | チェック | 税率・控除に影響 |
| 認定長期優良住宅 | チェック | 新築・居住用のとき 1,300万円控除 |
| 控除額 | 数値（円） | 建築年月日から自動計算 |

面積は小数点2位まで。建物床面積が 40〜240㎡（R8.4.1以降の下限40㎡）の外なら軽減措置の要件外として警告を出す（計算は止めない）。

#### 計算ロジック

**土地（宅地）**
1. 課税標準額 = 評価額 × 1/2（宅地特例）
2. 税額 = 課税標準額 × 3%
3. 住宅用地の税額軽減:
   - 控除額A = 45,000円
   - 控除額B = (課税標準額 ÷ 面積) × min(床面積×2, 200) × 3%
   - 適用控除 = max(A, B)
4. 納付税額 = 税額 - 適用控除（0円以上）

**土地（その他）**
1. 課税標準額 = 評価額（特例なし）
2. 税額 = 課税標準額 × 3%

**建物**
1. 課税標準額 = 評価額 - 控除額
2. 税率 = 3%（住宅用）/ 4%（非住宅）
3. 税額 = 課税標準額 × 税率

**建築年月日による控除額**

| 建築時期 | 控除額 |
|---------|--------|
| 1997年4月1日以降 | 1,200万円 |
| 1989年4月1日〜 | 1,000万円 |
| 1985年7月1日〜 | 450万円 |
| 1981年7月1日〜 | 420万円 |
| 1976年1月1日〜 | 350万円 |
| 1973年1月1日〜 | 230万円 |
| 1964年1月1日〜 | 150万円 |
| 1954年7月1日〜 | 100万円 |
| 1954年6月30日以前 | 控除なし |
| 新築 | 1,200万円（原則）/ 認定長期優良住宅 1,300万円 |

非住宅は控除なし。

**相続の場合**: 不動産取得税は非課税

#### 出力
- 結果ボックス: 土地（宅地/その他）・建物の内訳 + 合計
- 計算過程の詳細（トグル展開）

### 3.5 登録免許税シミュレーター（`/registration-tax`）

#### 入力項目

**共通設定**: 不動産取得税と同一（取引種別・計算対象）

**土地の情報**

| 項目 | 型 |
|-----|---|
| 固定資産税評価額 | 数値（円） |

**建物の情報**

| 項目 | 型 | 備考 |
|-----|---|------|
| 固定資産税評価額 | 数値（円） | |
| 居住用かどうか | チェック | |
| 住宅用家屋証明書あり | チェック | 居住用の場合のみ表示 |

#### 計算ロジック

**土地**
1. 課税標準額 = 評価額 × 持ち分（千円未満切捨）
2. 税率:
   - 売買: 2.0%（R8.4.1以降は本則。軽減1.5%は期限切れ）
   - 相続: 0.4%
   - 贈与: 2.0%
   - 新築（建物の新築に伴う土地の取得）: 2.0%
3. 税額 = 課税標準額 × 税率（百円未満切捨、最低1,000円）

**建物**
1. 課税標準額 = 評価額 × 持ち分（千円未満切捨）
2. 税率:

| 取引種別 | 通常 | 住宅用家屋証明あり |
|---------|------|-----------------|
| 売買 | 2.0% | 0.3% |
| 新築（保存登記） | 0.4% | 0.15% |
| 相続 | 0.4% | - |
| 贈与 | 2.0% | - |

3. 税額 = 課税標準額 × 税率（百円未満切捨、最低1,000円）

#### 出力
- 結果ボックス: 土地・建物の内訳 + 合計
- 計算過程の詳細（トグル展開）

---

### 3.6 2税まとめて計算（`/real-estate-summary`）

不動産取得税（§3.4）と登録免許税（§3.5）を1回の入力で同時に計算し、両方の結果と計算過程を A4横1枚に印刷する（印刷タイトル「不動産関連税シミュレーション」）。計算ロジックは各ページと同じ。

#### 入力の違い
- 取引種別を**土地・建物で別々に**選ぶ（土地の選択肢に「新築」は無い）
- 住宅用家屋証明書のチェックは既定でオン
- 建物の取引種別が「新築」のときだけ「新築建物の評価額を概算」を出す
  - 単価は徳島地方法務局・令和6年度基準（`lib/tokushima-new-building.ts`）
  - 用途: 居宅 / 共同住宅 / 店舗・事務所等 / 工場・倉庫等 / 附属家
  - 構造: 木造 / 軽量鉄骨造 / 鉄骨造 / 鉄筋コンクリート造
  - 概算額 = floor(床面積 × 単価) を建物の固定資産税評価額へ入れる

## 4. 共通機能

### 4.1 ナビゲーション
- 左のサイドバー（`Navigation.tsx`）
  - 上端: 業務支援ポータルへ戻るリンク
  - 贈与税関連: 贈与税 / 年数比較 / 贈与税 早見表
  - 不動産関連税: 不動産取得税 / 登録免許税 / 2税まとめて計算
  - 担当者名・電話番号の入力
  - 折りたたみ可（状態は localStorage `gift-tax-sidebar-collapsed`）。折りたたみ中はアイコンだけで、名前は title に出す
- 上部バー: 印刷ボタン
- モバイル: サイドバーはメニューボタンで開き、背景を押すと閉じる
- 「本文へ移動」のスキップリンクあり

### 4.2 ページ間の入力の共有
- **贈与税2ページ**（`/` と `/year-comparison`）: 金額・贈与区分・計算済みかを `GiftInputContext` で共有する。メモリのみなのでリロードすると消える。計算済みならページを移っても結果が出たまま
- **不動産3ページ**: 入力条件をページごとに localStorage へ保存し（`lib/real-estate-input-storage.ts`、キー `gift-tax-sim:valuations`）、ほかのページの入力を一括で引用できる（`useRealEstateImport`）
- 引用ボタンはインポートバーに配置（印刷時非表示）
- 全ページに「サンプルで試す」ボタン（`useSampleFill`）

### 4.3 数値入力
- 全角数字は自動で半角に変換
- カンマ区切りを自動フォーマット
- 数値以外の文字は自動除去
- 金額入力フィールドはRoboto Monoフォント（等幅）

### 4.4 印刷
- 全ページ **A4横1枚**（`@page { size: A4 landscape; margin: 8mm }`）
- 収まらない場合のみ `beforeprint` で実測し `zoom` を自動縮小（`lib/print-fit.ts`）
- 印刷時:
  - ナビゲーションタブ・計算ボタン・参照資料（税額の根拠）非表示
  - ヘッダーは透明背景 + 緑ボーダーに変更
  - ページタイトル（税目名）・会社情報・担当者名・作成日をヘッダーに表示
  - 不動産ページは入力欄を出さず「入力条件」サマリに置き換え、計算過程は自動展開
  - 不動産ページは 入力条件｜税額 の2カラム、計算過程と免責文が全幅
  - 再計算前（入力変更後）の税額は印刷しない
- 備考欄（`PrintRemarks`）は印刷のたびに書く前提で保存しない
- 縮小は `lib/print-fit.ts`（印字領域 281×194mm に合わせて `zoom` を縮める。拡大はしない）
- 印刷ボタンは上部バーに配置

### 4.5 会社情報
- 税理士法人マスエージェント
- 印刷用ヘッダー（`PrintHeader`）に表示

### 4.6 担当者情報
- サイドバーに入力欄
- localStorage に保存（キー: `gift-tax-staff-info`）
- 印刷用ヘッダーに反映

### 4.7 税額の根拠・参照資料
- 結果の下に税額の根拠（`TaxBasisNotice`）
- 不動産ページの参照資料（Q13・Q14・No.7191）は折りたたみ（`TaxReferenceSection`）で既定は閉じる。印刷しない

| キー | 中身 |
|---|---|

- `react`, `react-dom` → react チャンク
- `react-router-dom` → react-router チャンク

## 7. 非機能要件

### 7.1 パフォーマンス
- Chart.jsコンポーネントはlazy load（React.lazy + Suspense）
- lucide-reactは個別アイコンインポート（バンドルサイズ最適化）
- manualChunksによるバンドル分割

### 7.2 セキュリティ（本番nginx）
- X-Frame-Options: SAMEORIGIN
- X-Content-Type-Options: nosniff
- Referrer-Policy: strict-origin-when-cross-origin
- Permissions-Policy: camera/microphone/geolocation無効
- CSP: self + Google Fonts

### 7.3 入力バリデーション
- 贈与金額: 1円〜10億円
- 評価額: 1円〜100億円
- 計算結果の異常値チェック（isFinite, isNaN）
- 不正入力時はエラーメッセージ表示

## 8. Docker構成

### 8.1 共通Dockerfile
`docker/Dockerfile.vite-static`（7アプリ共有）。ステージは `base` → `deps` → `dev` / `builder` → `runner`。dev は `node`、runner は `nginx` ユーザーで動く（非 root）

起動・切り替えは `docker/scripts/manage.sh start [--prod] gift-tax-simulator`、再ビルドは `manage.sh build gift-tax-simulator`（稼働中のモードを踏襲）。素の `docker compose up` は本番を dev に作り替えるので使わない

### 8.2 ビルド引数

| 引数 | 値 |
|-----|---|
| APP_PORT | 3001 |
| APP_PATH | gift-tax-simulator |
| APP_TITLE | Gift Tax Simulator |
| APP_DESCRIPTION | 贈与税シミュレーション（税額計算・早見表・不動産取得税・登録免許税） |
| NPM_CACHE_ID | npm-store-gift-tax-simulator |

### 8.3 開発モード
- ターゲット: `dev`
- Vite dev server
- ボリューム: `./src:/app/src:ro`, `./index.html:/app/index.html:ro`
- ポーリングが無いので bind mount の変更を拾わない。ソースを直したら `docker restart gift-tax-simulator`
- `package.json` / `vite.config.ts` はイメージ同梱（変えたら `manage.sh build`）
- メモリ: 512M（上限）/ 128M（予約）、`NODE_OPTIONS=--max-old-space-size=384`

### 8.4 本番モード
- ターゲット: `runner`（nginx 1.27-alpine）
- 静的ファイル配信（gzip, キャッシュ制御）
- ボリュームマウントなし（`volumes: !reset []`）
- メモリ: 64M（上限）/ 16M（予約）
- ヘルスチェック: 30秒間隔
