# 動作確認用ダミーデータ

このフォルダの JSON は、画面からそのまま読み込めます。

読み込み方は2つあります。

- **会社の一覧の「JSONから案件を作る」**（おすすめ）: 新しい案件として取り込むので、ほかの案件に影響しません
- **帳票の操作帯の「読込 (JSON)」**: いま開いている帳票の中身をまるごと置き換えます。案件を開いているときは
  その案件が上書きされる（自動保存で DB にも入る）ので、実際の案件を開いたまま使わないこと。
  入力が残っていれば、置き換える前に確認が出て現在のデータを JSON で書き出します

## ファイル

- `01-general-large-company.json`
  - 一般の評価会社、大会社想定。
  - 第1表の1、第1表の2、第4表、第5表の基本連動確認用。
- `02-medium-company-with-dividend-rights.json`
  - 中会社想定。
  - 配当期待権、配当還元方式まわりの表示確認用。
- `03-stock-holding-specific-company.json`
  - 株式等保有特定会社想定。
  - 第7表、第8表、S1/S2 関連の確認用。
- `04-edge-zero-and-negative-values.json`
  - ゼロ値、マイナス値、未入力時判定の確認用。
  - 比準要素が 0 の強調表示や、⑪法人税の課税所得金額のマイナス入力確認に使います。
