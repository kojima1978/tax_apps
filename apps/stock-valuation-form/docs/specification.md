| 項目 | 内容 |

## 5. 機能仕様

### 5.0 評価目的による計算切替

画面上部の「評価目的」で次の2区分を選択する。未選択・旧JSONは従来どおり「相続税・贈与税の評価」として扱う。所得税基本通達59-6と法人税基本通達9-1-14は共通区分とし、同じ計算処理を適用する。

| 評価目的 | 根拠 | 計算上の取扱い |
|---|---|---|
| 相続税・贈与税の評価 | 財産評価基本通達178～189-7 | 通常の評価明細書どおり計算 |
| 所得税・法人税の時価評価 | 所得税基本通達59-6／法人税基本通達9-1-14 | 法人税額等相当額を控除しない。土地・上場有価証券は評価基準時点の価額。中心的な同族株主なら小会社扱い。59-6では株主判定を譲渡・贈与直前の議決権で行う |

評価目的は `table1_1._valuation_purpose`（共通区分は `special-market-value`）、中心的な同族株主等の特例指定は `table1_1._special_central_holder` に保存する。旧データとの互換性のため通常評価は空文字を既定値とし、旧区分値 `income-tax-59-6` と `corporate-tax-9-1-14` は共通区分へ読み替える。

### 5.1 共通機能

#### お客様向けサマリー

ヘッダーの「お客様サマリー」から、入力済みデータを顧客説明用に再構成したレポートを表示する。

- 基本情報: 会社名、代表者、評価基準日、評価目的
- 主要指標: 1株当たり純資産価額、類似業種比準価額、株式等・土地等保有割合
- 類似業種比準要素の感応度: 採用中の業種目を基準に、配当・利益・純資産が各1円増加した場合の1株評価額への概算影響を横棒で比較（医療法人は配当を対象外）
- 現状: 会社規模、評価会社区分、株主に応じた評価方式、評価要素差、資産構成
- 打ち手: 未入力確認、時価資料整備、資産構成見直し、株式移転計画などを入力内容に応じて優先度付きで表示
- 担当者コメント: `table1_1._summary_advisor_note` に保存し、JSON保存・読込の対象とする
- 「このサマリーを印刷」でA4顧客報告書として印刷できる

サマリーは入力内容から都度算出し、帳票の計算値を重複保存しない。入力不足時は断定的な判定を表示せず、確認すべき項目を優先度「高」の打ち手として提示する。

### 5.2 第１表の１ — 株主判定・会社規模

- 会社情報（会社名・所在地・代表者・課税時期・事業年度・業種目番号）と株主一覧を入力する
- 業種目番号は API から取得した業種目マスタのプルダウンで選択し、隣接する業種目名の欄が自動で埋まる（`f23`→`f22`、`f26`→`f25`、`f29`→`f28`）
- 株主一覧は続紙で用紙を追加でき、追加・削除は入力欄の直下の操作帯（`SheetOps`）で行う

#### 計算ロジック

```
議決権割合（同族） = 同族チェック株主の議決権合計 ÷ 全議決権合計 × 100
議決権割合（筆頭） = 筆頭チェック株主の議決権合計 ÷ 全議決権合計 × 100
```

**同族判定**

| 条件 | 判定結果 |
|---|---|
| 同族割合 > 50% | 同族株主等 |
| 同族割合 ≤ 50% | 同族株主等以外 |

**少数株主の評価方式判定**（決定木）

1. 役員である → 原則的評価方式等
2. 役員でない かつ 中心的同族株主がいる → 原則的評価方式等
3. 中心的同族株主がいない かつ 中心的株主がいる → 配当還元方式
4. いずれにも該当しない → 原則的評価方式等

### 5.3 第１表の２ — 会社規模判定

#### 計算ロジック

```
従業員合計 = 常勤従業員 + パート等の勤務時間換算
㋻         = 総資産価額の区分と従業員数の区分のうち下位
会社規模   = ㋻ と ㋕（取引金額の区分）のうち上位
```

**判定基準**

| 判定 | 条件 |
|---|---|
| 大会社（強制） | 従業員 ≥ 70人 |
| 大〜小 | 上記の㋻・㋕から決定 |
| 小会社（強制） | 評価目的が所得税・法人税の時価評価で、中心的な同族株主に該当する場合 |

**会社規模の結果**

| 区分 | Lの割合 |
|---|---|
| 大会社 | — |
| 中会社の大 | 0.90 |
| 中会社の中 | 0.75 |
| 中会社の小 | 0.60 |
| 小会社 | — |

閾値は業種区分（卸売業／小売・サービス業／その他）ごとに `Table1_2Grid.tsx` の定数表で持つ。業種区分は判定基準の欄から直接選択する。

### 5.4 第２表 — 特定の評価会社判定

- 比準要素数1の会社・比準要素数0の会社の判定
- 株式等保有特定会社・土地保有特定会社の判定
- 開業後3年未満の会社等・開業前または休業中の会社・清算中の会社の判定
- 判定結果に応じて、記載が必要な様式をサイドバーと印刷ダイアログへ伝える

### 5.5 第３表 — 一般の評価会社の株式の価額

- 原則的評価方式（類似業種比準価額と純資産価額の併用。Lの割合は第１表の２から連動）
- 特例的評価方式（配当還元方式）
- 適用する方式は第１表の株主判定に連動した自動選択。様式の区分見出しをクリックすると固定でき、もう一度押すと自動に戻る

### 5.6 第４表の１ — 比準要素の金額

- 1株当たりの資本金等の額、直前期末の発行済株式数・自己株式数、50円換算の株式数
- 1株当たりの配当金額（直前期・直前々期）、利益金額（非経常的な利益の控除を含む）、純資産価額
- 医療法人は配当を対象外とし、該当欄を入力不可にする

### 5.7 第４表の２ — 類似業種比準価額

- 第１表の１で選んだ業種目番号（`f23` / `f26` / `f29`）と課税時期（`f14_g` / `f14_y` / `f14_m`）から、API 経由で類似業種の株価・配当・利益・純資産を引く
- 比準割合を算出し、会社規模に応じた斟酌率を掛けて類似業種比準価額を確定する

### 5.8 第５表 — 1株当たりの純資産価額

資産・負債の明細を入力する（続紙で最大38行）。

#### 計算ロジック

```
⑤ 相続税評価額純資産 = max(0, 資産評価額合計 − 負債評価額合計)
⑥ 帳簿価額純資産     = max(0, 資産帳簿合計 + 現物出資評価 − 現物出資帳簿 − 負債帳簿合計)
⑦ 評価差額           = max(0, ⑤ − ⑥)
⑧ 法人税等相当額     = 特例時 0、それ以外 floor(⑦ × 0.38)     ← 令和8年様式38%
⑨ 課税時期純資産     = ⑤ − ⑧
⑩ 発行済株式数       = 発行済株式 − 自己株式
⑪ 1株当たり純資産    = ⑩ > 0 ? floor(⑨ × 1000 ÷ ⑩) : —
⑫ 80%純資産価額      = floor(⑪ × 0.8)      ← 議決権割合 ≤ 50%の場合のみ
```

評価目的が所得税・法人税の時価評価のときは⑧を控除しない。

### 5.9 第６表 — 特定の評価会社の株式の価額

5種類の評価区分に対応する。

| 区分 | 評価方法 |
|---|---|
| ④ 比準要素数1の会社 | 類似業種比準25% + 純資産75%のブレンド |
| ⑤ 株式等保有特定会社 | S1 + S2（第７表の３の㉗を参照） |
| ⑥ 土地保有特定会社 | 純資産価額方式 |
| ⑦ 開業後3年未満の会社等 | 純資産価額方式 |
| ⑧ 開業前・休業中の会社 | 純資産価額方式 |

第３表と同じく、適用方式は自動選択＋区分見出しのクリックによる固定に対応する。

### 5.10 第７表の１ — 受取配当金収受割合

- 受取配当金額・営業利益金額（直前期・直前々期）から受取配当金収受割合を算出
- S1の比準要素（B・C）の修正

### 5.11 第７表の２ — S1の類似業種比準価額

- 修正後の比準要素で S1 の類似業種比準価額を計算

### 5.12 第７表の３ — S1の純資産価額・S2・株式の価額

- S1の純資産価額の修正
- S2（株式等の価額）の算出

| `formGeometry.ts` | `ui/formGeometry.ts` | 様式原本の実測mm座標 |

各様式は「セル定義の配列 + 計算関数」として `components/tables/<表>/` 以下に置く。個別の入力コンポーネントは持たず、`GridForm` がセルの種別に応じて描き分ける。

### 7.2 適用方式の選択セル (`tables/shared.ts`)

第３表と第６表で共通の `methodPickCell` のみを提供する。

| 関数 | 説明 |
|---|---|
| `methodPickCell(opts)` | 適用方式を様式の区分見出しそのものでクリックして選ばせるセル属性を返す。既定は第１表の株主判定に連動した自動選択、クリックで固定、再クリックで自動へ戻る |

採用中の着色は様式にない表示なので画面限定（`highlightScreenOnly`）とし、自動で選ばれた区分と手で固定した区分を枠の色で見分けられるようにしている。

## 9. API仕様

すべて `/stock-valuation-form/api` 配下。入力データは扱わず、業種目マスタと業種目別株価等のみを対象とする。

| メソッド | パス | 用途 |
|---|---|---|
| GET | `/health` | 死活監視（seed 失敗時は 503） |
| GET | `/industry-years` | 登録済みの年分一覧 |
| GET | `/industry-categories` | 業種目マスタ |
| GET | `/industry-metrics` | 業種目別の配当・利益・純資産 |
| GET | `/industry-dataset` | フロントが使う一括取得 |
| GET | `/industry-years/:gregorianYear/export` | 年分のJSON書き出し |
| POST | `/industry-years` | 年分の新規登録 |
| POST | `/industry-years/:gregorianYear/monthly-prices` | 月別株価の登録 |
| PATCH | `/industry-years/:gregorianYear/categories/:number` | 業種目の訂正 |
| DELETE | `/industry-years/:gregorianYear/monthly-prices/:y/:m` | 月別株価の削除 |

CLI（`npm run industry:export` / `industry:import`）は管理画面の「JSONで入出力」と同じ経路を使う。年分の削除APIは無いので、登録済みの年分へは `--months-only` で月別株価だけ上書きする。

## 11. 制約・前提条件

| 項目 | 内容 |
|---|---|
| バックエンド | Hono + Prisma（業種目マスタ・業種目別株価等の配信と登録のみ） |

| ブラウザ対応 | モダンブラウザ（Chrome, Edge, Firefox, Safari） |
| 印刷 | A4縦のみ |
| Gateway | nginx に登録済み（`/stock-valuation-form/`） |
