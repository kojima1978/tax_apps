# 株式評価フォーム サンプルJSON

画面からそのまま読み込めるサンプルデータです。全パターンの評価基準日は令和8年4月で、同年分の類似業種マスターを参照します。

読み込み方は2つあります。

- **会社の一覧の「JSONから案件を作る」**（おすすめ）: 新しい案件として取り込むので、ほかの案件に影響しません
- **帳票の操作帯の「読込 (JSON)」**: いま開いている帳票の中身をまるごと置き換えます。案件を開いているときは
  その案件が上書きされる（自動保存で DB にも入る）ので、実際の案件を開いたまま使わないこと。
  入力が残っていれば、置き換える前に確認が出て現在のデータを JSON で書き出します

| ファイル | 主な確認内容 |
|---|---|
| `01-minimal.json` | 小会社・基本的な商社モデル |
| `02-small-company.json` | 小会社・土地を保有するサービス会社 |
| `03-medium-company.json` | 中会社・製造業モデル |
| `04-large-company.json` | 大会社・従業員70人以上 |
| `05-multiple-shareholders.json` | 複数株主・同族グループ50%以下 |
| `06-net-assets.json` | 土地保有割合が高い会社 |
| `07-dividend-data.json` | 株式等保有割合が高い会社 |
| `08-special-company.json` | 所得税59-6／法人税9-1-14の共通時価評価・中心的同族株主 |
| `09-linked-fields.json` | 持分の定めのある医療法人・配当要素除外 |
| `10-full-scenario.json` | 2業種目比較、資産・負債・担当者コメントを含む総合例 |

金額欄は原則として帳票の表示単位（千円）、株数欄は株、類似業種目は業種目番号で保存しています。類似業種の配当・利益・純資産・株価は、読込時に業種マスターから自動補完されます。
